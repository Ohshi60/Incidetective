# Incidetective

An AI-assisted incident investigation tool for backend services

## Problem

Investigating service incidents often requires engineers to correlate
logs, identify relevant events, and assemble evidence before diagnosing
a failure.

## Goals

- Accept and store simulated incidents.
- Search synthetic application logs for relevant evidence.
- Generate structured investigation reports.
- Integrate an AI provider without requiring a paid API.
- Demonstrate testing, observability, and infrastructure as code.

## Planned technology

- TypeScript and Node.js
- Fastify and PostgreSQL
- Vitest and Docker Compose
- A mock AI provider and optional local language model
- Terraform and Proxmox for deployment

## Project status

Early development. The implementation and architecture will evolve
as the project progresses.
